# 🧠 Carte mentale — Leçon 4 : Opérations mathématiques

> 💡 Idée centrale : 5 symboles pour calculer, et **un piège** à connaître.

```
                    ➗ OPÉRATIONS
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
   🔢 Les 5 opérateurs  ✨ Le modulo %   ⚠️ Division entière
        │                 │                 │
   +  addition           = le RESTE         10 / 3 = 3
   -  soustraction       d'une division     (pas 3.33 !)
   *  multiplication     10 % 3 = 1         │
   /  division                              avec double :
   %  modulo                                10.0 / 3.0 = 3.33
```

🌙 *Le truc à garder en tête : entre entiers, la division coupe la virgule.*
