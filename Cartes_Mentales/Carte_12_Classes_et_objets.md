# 🧠 Carte mentale — Leçon 12 : Les classes et les objets

> 💡 Idée centrale : la **classe** est le **moule**, l'**objet** est le **gâteau**. 🎂

```
                 🎂 CLASSES & OBJETS
                        │
      ┌─────────────────┼─────────────────┐
      │                 │                 │
  🧱 Classe         🍰 Objet          🔧 Son contenu
      │                 │                 │
  le moule / plan   fabriqué avec      ├─ Attributs
  (Majuscule !)     new                │   = caractéristiques
      │                 │              │   (marque, couleur)
  décrit la forme   Voiture v =        └─ Méthodes
                    new Voiture();         = actions
                        │                  (demarrer())
                    accéder avec
                    le point :  v.demarrer()
```

🌙 *À retenir ce soir : 1 moule (classe) → autant de gâteaux (objets) qu'on veut, avec `new`.*
