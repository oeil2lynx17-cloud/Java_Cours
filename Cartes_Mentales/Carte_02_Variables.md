# 🧠 Carte mentale — Leçon 2 : Variables et types

> 💡 Idée centrale : une **variable** est une **boîte** qui range une valeur.

```
                       📦 VARIABLES
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
   🏷️ Anatomie         🎨 Les 4 types      ⚠️ Règles d'or
        │                   │                   │
   type nom = valeur ;      ├─ int → entier     ├─ String = majuscule
        │                   ├─ double → décimal  ├─ texte entre " "
   ex: int age = 50 ;       ├─ boolean → vrai/faux ─ on assigne avec =
                            └─ String → texte    └─ ligne finit par ;
                                (avec " ")
```

🌙 *À retenir ce soir : nombres SANS guillemets, texte AVEC guillemets.*
