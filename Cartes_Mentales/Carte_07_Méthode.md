# 🧠 Carte mentale — Leçon 7 : Les méthodes

> 💡 Idée centrale : une **méthode** est une **fiche recette** qu'on écrit une fois et qu'on réutilise. 🍝

```
                    🍝 MÉTHODES
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
   📦 C'est quoi      🏗️ Structure      🔁 2 actions
        │                 │                 │
   bloc d'instructions  static void        ├─ Déclarer
   RÉUTILISABLE         nom() {            │   (écrire 1 fois)
        │                  ...             └─ Appeler
   = ne pas se répéter  }                      nom() ;
     (DRY)
        │
   ⚠️ Règles
        │
   ├─ nom en minuscule (camelCase)
   ├─ ( ) obligatoires
   └─ ; à l'appel
```

🌙 *À retenir ce soir : on écrit la recette UNE fois, on l'appelle autant qu'on veut.*
