# 🧠 Carte mentale — Leçon 5 : Les conditions (if / else)

> 💡 Idée centrale : **SI** c'est vrai → je fais ça, **SINON** → je fais autre chose. ☔

```
                  ☔ CONDITIONS
                        │
      ┌─────────────────┼─────────────────┐
      │                 │                 │
  🔀 if / else     ⚖️ Comparateurs   🚧 Structure
      │                 │                 │
  if = "si"         ==  égal           if (condition) {
  else = "sinon"    !=  différent          ...
      │             >   supérieur       } else {
  ⚠️ = assigne      <   inférieur          ...
     == compare     >=  sup. ou égal    }
                    <=  inf. ou égal
```

🌙 *Le piège classique à mémoriser : `=` range une valeur, `==` compare deux valeurs.*
