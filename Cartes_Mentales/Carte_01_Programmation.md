# 🧠 Carte mentale — Leçon 1 : La programmation

> 💡 Idée centrale : un **programme**, c'est une **recette** que l'ordinateur suit.

```
                    🌳 PROGRAMMATION
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
   📝 C'est quoi      👥 Les acteurs    🏗️ Structure
        │                 │                 │
   suite d'instructions   ├─ Programmeur    ├─ class → la boîte
   = une recette          │   (écrit)       ├─ main() → la porte d'entrée
                          └─ Ordinateur     └─ { } → ouvre / ferme
                              (exécute)
                          │
                    💬 Afficher
                          │
        ┌─────────────────┼─────────────────┐
   System.out.println   " " = texte         ; = fin
   ("...")              (String)            d'instruction
```

🌙 *Avant de dormir, retiens juste : la machine lit de haut en bas, et chaque ligne finit par `;`*
